# Paws & Hearts Animal Rescue Website

A responsive static website created for Paws & Hearts, a fictional animal rescue organisation dedicated to rescuing, rehabilitating and rehoming abandoned dogs and cats.

This project was built as a multi-page front-end website using HTML and CSS only. It includes a welcoming homepage, information pages, adoption enquiry form, contact page, and a consistent branding/style system throughout the site.

## Project overview

Paws & Hearts aims to raise awareness for animal welfare while encouraging people to adopt, volunteer, or support rescue work. The website is designed to feel warm, caring, and professional, with a soft peach-and-navy palette, rounded cards, responsive sections, and clear calls to action.

## Pages included

The website currently contains the following pages:

- Home page: welcoming hero section, mission overview, available animals, adoption process, and call-to-action banner
- About Us page: rescue story, mission, and organisation values
- Our Work page: rescue, medical care, foster support, rehabilitation, adoption matching, and awareness work
- Enquiry page: adoption form for potential adopters
- Contact page: organisation details, map embed, and contact form

## Design and features

- Clean, modern navigation bar with link structure across all pages
- Hero banner with strong messaging and CTAs
- Animal cards featuring rescue pets and adoption prompts
- Service cards for the organisation’s key activities
- Soft, consistent colour palette and accessible spacing throughout
- Responsive layout for desktop, tablet, and mobile screens
- Contact and enquiry forms styled to match the website theme
- Embedded Google Map on the contact page
- Reusable CSS styling across all pages

## File structure

- index.html — homepage
- about_us.html — about page
- services.html — our work page
- enquiry.html — adoption enquiry page
- contact.html — contact page
- css/style.css — main stylesheet
- _images/ — images used throughout the site

## Styling notes

The website uses a custom CSS theme with:

- warm neutral background tones
- peach accent colours for buttons and highlights
- dark navy text and footer styling
- rounded cards, soft shadows, and border details
- grid-based layouts for sections and responsive display
